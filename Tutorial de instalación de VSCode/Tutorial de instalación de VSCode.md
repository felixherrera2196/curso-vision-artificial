# Tutorial de instalación de VSCode

**Video de apoyo:** [cómo instalar VS Code en YouTube](https://www.youtube.com/watch?v=6aw2zyeSzZ8).

Esta guía explica cómo instalar **Visual Studio Code (VS Code) en Windows 11**, paso a paso. No necesitas experiencia en tecnología. Necesitas conexión a Internet para descargarlo.

## 1. Descargar el instalador

1. Abre tu navegador, por ejemplo Microsoft Edge o Google Chrome.
2. Haz clic en la barra de direcciones de la parte superior, escribe **https://code.visualstudio.com/Download** y presiona **Enter**.
3. En la sección **Windows**, selecciona **User Installer**. Esta opción instala el programa para tu usuario y normalmente no requiere permisos de administrador.
4. Elige **x64** si tu computadora tiene un procesador Intel o AMD, como la mayoría de los equipos. Si utiliza un procesador ARM, elige **Arm64**. Puedes comprobarlo en **Inicio → Configuración → Sistema → Información → Tipo de sistema**.
5. Espera a que termine la descarga. El archivo tendrá un nombre parecido a `VSCodeUserSetup-x64-...exe` y quedará normalmente en **Descargas**.

VS Code es gratuito. Utiliza el enlace oficial indicado arriba.

## 2. Instalar VS Code

1. Abre el **Explorador de archivos**: es el icono de carpeta de la barra de tareas. También puedes presionar **Windows + E**.
2. En el lado izquierdo, haz clic en **Descargas**.
3. Haz doble clic en el instalador que descargaste.
4. Si Windows pide autorización para realizar cambios, comprueba que sea el instalador oficial de VS Code y haz clic en **Sí**. Si solicita una contraseña que no tienes, pide ayuda a quien administra la computadora.
5. Lee el acuerdo de licencia, marca **Acepto el acuerdo / I accept the agreement** si estás de acuerdo y haz clic en **Siguiente / Next**.
6. En la pantalla de ubicación, deja la carpeta que viene seleccionada y pulsa **Siguiente / Next**.
7. Conserva el nombre propuesto para el menú Inicio y pulsa **Siguiente / Next**.
8. Si aparece **Tareas adicionales / Select Additional Tasks**, puedes marcar **Crear un icono en el escritorio / Create a desktop icon** para encontrarlo fácilmente. Conserva las otras opciones predeterminadas y pulsa **Siguiente / Next**.
9. Haz clic en **Instalar / Install**. Espera a que termine la barra de progreso; no cierres el instalador mientras trabaja.
10. En la última pantalla, deja marcada **Ejecutar Visual Studio Code / Launch Visual Studio Code** y haz clic en **Finalizar / Finish**.

## 3. Comprobar que quedó instalado

1. Debe abrirse la ventana principal de VS Code. Puede mostrar una pantalla de bienvenida: eso es normal.
2. Si no se abre automáticamente, haz clic en **Inicio**, escribe `Visual Studio Code` y haz clic en el resultado.
3. Si aparece la ventana del programa, **VS Code está instalado correctamente**.

Aquí termina la instalación. Puedes cerrar el programa.
